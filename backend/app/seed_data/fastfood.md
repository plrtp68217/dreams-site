## Начало сна

1. В больнице Еве приносят ужин. Запах пережаренного масла усиливается, лампы мигают, палата превращается в ресторан.
2. Ева оказывается за кассой в форме сотрудника. На бейджике: «Ева. Стажёр. Испытуемая. Счастливый сотрудник месяца».
3. Администратор поручает обслужить семь посетителей. После завершения каждого обслуживания появляется следующий посетитель.

## Семь посетителей

::: карточка Мужчина без лица
1. Мужчина заказывает бургер без булки, картошку без соли, напиток без вкуса и игрушку без лица. Просит найти его лицо.
2. Ева идёт в уборную, находит салфетку и протирает зеркало.
3. В отражении появляется лицо мужчины и на секунду сменяется лицом врача из больницы.
4. Ева возвращается на кухню, собирает заказ и отдаёт мужчине.
5. Получает фрагмент медкарты: «Испытуемая не распознаёт сотрудников после третьей фазы сна».
:::

::: карточка Бабушка с тележкой
1. Бабушка заказывает маленькую картошку, чай без сахара и соус «Одобрено». Для выдачи нужен талон.
2. Ева идёт в зал ожидания и находит талон среди манекенов с номерками.
3. Собирает заказ на кухне и выдаёт его по талону.
4. Бабушка отдаёт монету. Она понадобится для доступа в детскую зону.
:::

::: карточка Человек в костюме бургера
1. Посетитель проводит проверку вместо заказа. На терминале появляется вопрос: «Вы довольны условиями смены?».
2. Ева выбирает «Да, но с пониманием исторического контекста». Терминал принимает ответ.
3. По поручению проверяющего Ева вешает плакат «Свободная касса — счастливая касса».
4. Проверка завершена. К кассе подходит девочка.
:::

::: карточка Девочка из детской зоны
1. Девочка заказывает детский бургер, молочный коктейль и игрушку, которая не кричит ночью.
2. Ева использует монету бабушки и попадает в детскую зону.
3. В автомате выбирает капсулу с маленькой койкой.
4. На кухне собирает заказ, добавляет игрушку и отдаёт девочке.
5. Получает рисунок: девочка, ресторан, больничная койка, женщина в халате и красная кнопка. Подпись: «Я сама разрешила?».
:::

::: карточка Мужчина с печатью вместо лица
1. Мужчина заказывает бургер «Стабильный», картошку «Без перемен», напиток «Традиционный» и соус «Не раскачивать». Требует заверить документы печатью.
2. Ева находит ключ или запасной пропуск в раздевалке и открывает кабинет администратора.
3. В кабинете находит печать и форму добровольного согласия. Ставит печать на согласие.
4. Открывается воспоминание: Ева сидит за столом перед документом, в руке ручка. Голос говорит: «Вы можете отказаться в любой момент».
5. Ева возвращается к кассе и завершает обслуживание. В дневнике появляется запись «Согласие».
:::

::: карточка Солдат-курьер
1. Курьер ставит посылку на стойку: «Доставка из прошлого. Получатель — Ева. Статус: не помнит».
2. Ева расписывается на терминале и получает пакет.
3. Внутри — больничный браслет, студенческий билет, обгоревший чек, фотография ресторана и салфетка с жирным пятном.
4. Ева читает студенческий билет: она студентка и получила допуск к эксперименту.
5. По фотографии находит закрытое окно выдачи заказов. На снимке проявляется силуэт врача.
6. Открывается фрагмент памяти: до больницы Ева участвовала в исследовательской программе.
:::

::: карточка Клоун — невозможный заказ
1. К кассе подходит клоун Ронни. На терминале появляется заказ из шести позиций.
2. Ева берёт старый бейджик в раздевалке — «Имя Евы».
3. В детской зоне забирает «Первый сон».
4. В кабинете администратора забирает «Настоящую причину».
5. У старой фритюрницы находит соус «Вспомни».
6. На кассе забирает чек, на терминале доставки — подпись.
7. Собрав все шесть позиций, возвращается к клоуну и отдаёт заказ.
8. Клоун достаёт из пакета подписанный документ. Спрашивает: «Ты помнишь, как пахла ручка, когда ты подписывала?». Ева отвечает: «Нет…».
9. Документ остаётся у Евы. Тело клоуна вытягивается, руки удлиняются, улыбка рвётся. Начинается погоня.
:::

## Погоня и пробуждение

1. Ева бежит от клоуна. Кухня вытягивается в коридор, детская зона становится лабиринтом. Касса без остановки печатает «Согласие получено».
2. Клоун кричит: «Ты не пленница! Ты клиент! Ты сама сделала заказ!».
3. Ева добегает до запертой двери с табличкой «Выход только по чеку».
4. Использует подписанный чек-документ. Дверь открывается в больничный коридор.
5. Ева просыпается на полу больницы. В руке — настоящая салфетка с жирным пятном.
6. На салфетке проявляется текст: «Эксперимент №1: сенсорная привязка через запах. Реакция испытуемой: сильная тревога, частичная фрагментация памяти. Испытуемая продолжает настаивать на участии».

> **Ева (шёпотом):** Я… сама?

7. Из больничного динамика доносится смех клоуна. Сон завершён.
